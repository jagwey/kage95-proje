# KAGE95 Manga

KAGE95, orman yesili temaya sahip sade bir manga katalog arayuzudur.

## Icerik

- Wind Breaker ve Vinland Saga katalog kartlari
- Manga arama ve tur filtreleme
- Favorilere ekleme
- Manga detay penceresi
- Responsive mobil tasarim

## Calistirma

```bash
npm install
npm run dev
```

Uretim derlemesi:

```bash
npm run build
```

## Deploy

`main` dalina push edildiginde GitHub Actions, projeyi GitHub Pages'e otomatik olarak deploy eder.
